Anatomy of a skill

One folder. Loaded only when it's relevant.

The agent reads each skill's name and description up front, then loads the full instructions only when your request matches. Big references and scripts stay out of the context until they're needed.

  • 1SKILL.md: YAML front matter with a name and a trigger-rich description, then the workflow.
  • 2references/: templates, checklists and examples the skill can open on demand.
  • 3scripts/: helpers for steps that should be exact and repeatable.
cover-letter-generator/
├── SKILL.md
│   ---
│   name: cover-letter-generator
│   description: Generate personalized,
│     compelling cover letters by analyzing
│     job descriptions and resumes…
│   ---
├── README.md
└── references/
    ├── best_practices.md
    └── examples.md
